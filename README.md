# Royi 的数学实验室

13 节中文互动课程，用可拖动的坐标图、逐步推导和即时练习探索平面直角坐标系、一次函数和反比例函数。

## 使用

下载并解压整个项目，双击 index.html 即可离线学习。请将四个网页文件放在同一目录。学习进度由当前浏览器在可用时保存在本机。

## 发布

将项目文件放在 GitHub 公共仓库根目录。在 Settings → Pages 选择 Deploy from a branch，选择 main 和 / (root)，保存。也可以将四个网页文件上传到其他静态网站托管服务。网站无需构建、数据库或外部脚本。

## 许可

本仓库原创代码和课程文字采用 MIT 许可证。教材页码仅供对照，教材扫描件不包含在项目内。
